# 5W1H Context Gatherer

Claude Code 스킬 — 5W1H 프레임워크(Who, What, When, Where, Why, How)로 사용자 요청의 빠진 맥락을 파악하고 선택형 UI로 수집합니다.

## 설치

Claude Code에서 아래 2줄을 순서대로 입력하세요:

```bash
/plugin marketplace add https://github.com/ybgwon96/5h1w.git
/plugin install 5h1w@ybgwon96-5h1w
```

## 동작 방식

| 빠진 항목 | 동작 |
|----------|------|
| 0개 | 바로 작업 시작 |
| 1개 | 인라인으로 간단히 질문 |
| 2개+ | 5W1H 태그가 붙은 선택형 UI로 질문 |

## 예시

"꽃집 사이트 만들어줘" →

```
┌─────────────────────────────────┐
│ Why(왜)                         │
│ 사이트의 주요 목적이 무엇인가요?   │
│ ○ 소개 + 문의 (추천)             │
│ ○ 온라인 주문                    │
│ ○ 소개 + 주문 모두               │
├─────────────────────────────────┤
│ How(어떻게)                      │
│ 원하는 분위기는?                  │
│ ○ 따뜻한/내추럴                  │
│ ○ 고급스러운/모던                 │
│ ○ 화사한/컬러풀                  │
└─────────────────────────────────┘
```

## 특징

- **비개발자 친화적** — 기술 용어 없이 쉬운 말로 질문, 개발자에게는 개발 수준에 맞춤
- **5W1H 프레임워크 체험** — 선택 UI의 header에 Who/What/When/Where/Why/How 태그 노출
- **최소 간섭** — 빠진 정보가 2개 이상일 때만 발동, 단순 요청은 스킵
