# Block Blast

> 네온 블록을 드래그해 줄을 없애는 **8×8 블록 퍼즐** — 콤보 & 연속(streak) 보너스 / 모바일 PWA

2026년 글로벌·국내 캐주얼 차트 1위를 휩쓴 **블록 블라스트** 장르를 직접 구현한 게임입니다.
한 번에 주어지는 블록 3개를 8×8 보드에 드래그해서 놓고, **가로/세로 줄이 꽉 차면 폭파**됩니다.
한 수에 여러 줄을 동시에 지우면 **콤보 배수**, 연속으로 줄을 지우면 **연속 보너스**가 붙어
점수가 눈덩이처럼 불어납니다. 더 놓을 곳이 없으면 게임 오버.

폰에서 **"홈 화면에 추가"** 하면 전체화면 네이티브 앱처럼 실행되고, 오프라인에서도 동작합니다.

## 규칙 (5초 룰)

1. 트레이의 블록 3개를 보드로 **드래그**해 배치 (손가락 위로 살짝 떠서 보임)
2. **가로 줄 또는 세로 줄이 완전히 차면 자동 제거** + 점수
3. 한 수에 **여러 줄 동시 제거 = 콤보 배수**, **연속 제거 = streak 보너스**
4. 블록 3개를 다 놓으면 새 블록 3개 등장
5. 어떤 블록도 놓을 자리가 없으면 **GAME OVER**

| 동작 | 점수 |
| --- | --- |
| 블록 배치 | 칸 수 만큼 |
| 줄 제거 | (지운 칸 × 10) × 동시 줄 수 + 연속 보너스 |

## 기술 스택

- **Vite** + **TypeScript** — 빠른 개발 / 타입 안전성
- **HTML5 Canvas 2D** — 의존성 없는 자체 렌더링 (네온 글로우, 파티클, 화면 흔들림, 점수 팝업)
- **Web Audio API** — 에셋 없는 절차적 효과음 (배치/제거/콤보)
- **PWA** — 직접 작성한 매니페스트 + 서비스워커로 설치/오프라인 지원
- 포인터 드래그(터치/마우스 공통), 모바일 햅틱, 고해상도(DPR) 대응, 포트레이트 최적화

## 개발

```bash
npm install      # 의존성 설치
npm run dev      # 개발 서버 (http://localhost:5173, 같은 와이파이의 폰에서도 접속 가능)
npm run build    # 타입 체크 + 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

폰에서 바로 테스트하려면 `npm run dev` 실행 후 터미널에 표시되는 네트워크 주소를
폰 브라우저에서 열면 됩니다.

## 프로젝트 구조

```
index.html              진입 HTML (뷰포트/PWA 메타)
public/
  manifest.webmanifest  PWA 매니페스트
  sw.js                 서비스워커 (오프라인 캐시)
  icons/                앱 아이콘 (SVG)
src/
  main.ts               부트스트랩 · 캔버스/DPR · 게임 루프 · 포인터 입력
  game.ts               보드 · 블록(폴리오미노/회전) · 배치/줄제거/콤보 · 렌더링
  particles.ts          파티클 시스템
  audio.ts              Web Audio 효과음
  storage.ts            최고 점수 / 음소거 저장
  style.css             전체화면 캔버스 스타일
```
